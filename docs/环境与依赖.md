# 环境与依赖

本包没有将“当前机器安装的版本”冒充“所有历史实验使用的版本”。
第二篇当前解码环境：`/root/miniconda3/envs/speechbrain-pj/bin/python`。
第一篇训练历史使用 `asr_env`；整理时另外保存服务器各环境的实际版本快照，供核对。
不要用第二篇环境覆盖第一篇训练环境。

核心依赖按阶段分开：
- 数据与统计：numpy、pandas、jiwer、tqdm；数字副指标需要 num2words。
- Whisper HF 建库/训练：torch、torchaudio、transformers；训练另需 speechbrain、hyperpyyaml。
- 伪标签/标准解码：faster-whisper（CT2 格式模型，与 HF 目录不同）。
- 检索：与 GPU/CUDA 兼容的 FAISS，沿用现有成功环境。
- LAMP：Apertium Kazakh 分析器；LM 重排使用对应 mGPT 模型。

`audit/imports.json` 是静态导入清单，不是可直接 pip install 的包名表；它包含本地模块和可选分支。没有把整套 icefall/上游框架复制进发布包。跨架构实验使用原 recipe 与其配置，并参照跨模型指南。


本次服务器快照显示：`asr_env` 没有 faster-whisper/ctranslate2，因此第一篇伪标签阶段可用 speechbrain-pj，训练阶段仍用 asr_env；pipeline 使用调用它的那个 Python。FAISS 在 Python 包元数据中没有 faiss-gpu/faiss-cpu 条目不代表无法 import（可能是 conda 或其他安装方式），不要据此覆盖现有 FAISS。
